# Clustering & Types of Clustering Algorithms

## Day 72

This project covers major clustering approaches using Scikit-Learn.

### Algorithms
- K-Means
- Hierarchical / Agglomerative Clustering
- DBSCAN
- Mean Shift
- Gaussian Mixture Models

### Supporting concepts
- Inertia
- Silhouette Score
- Feature Scaling
- PCA for visualization

## Requirements

```bash
pip install numpy pandas matplotlib scikit-learn
```
